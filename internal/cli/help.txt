zel - minimal AI coding agent

USAGE
  zel                     open the TUI
  zel -p PROMPT [--provider NAME] [--model MODEL] [--effort LEVEL]
                          run one task without the TUI: prints the session ID,
                          then the final answer (exit 0, nonzero on error, 130
                          when cancelled); flags apply to this run only
  zel update              replace this binary with the latest release
  zel version
  zel help

CONFIG
  Providers, models and preferences live in the UI (Ctrl+K) and in ~/.zel/zel.db.
  Extensions: ~/.zel/init.lua, then the nearest .zel/init.lua up from here.
  A file returns {instructions, tools, hooks, completions} or a list of them:

    return {
      instructions = "Read code first.",
      tools = {hello = {desc = "greets. args: who", fn = function(a) return "hi " .. a.who end}},
      hooks = {turn_end = function(answer, running) end},
      completions = {plan = function() return read("PLAN.md") end},
    }

  Hooks: session_created(), message(text, notice), turn_end(answer, running),
  session_closed(reason). Menu > Reload rereads the files. See docs/lua-api.md.

KEYS
  Ctrl+K menu  Ctrl+M models  Ctrl+R resume  Ctrl+N new  Ctrl+I info
  Ctrl+T tracing  Ctrl+Y copy answer  Ctrl+D stop the turn  Ctrl+Q quit
  @ completes paths, # completes prompt completions

ENVIRONMENT
  ZEL_HOME   data directory (default ~/.zel)
  sh() gets ZEL_SESSION_ID and ZEL_MODE

Lua and shell run with your permissions and network access; there is no sandbox.
