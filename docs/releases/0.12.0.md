# 0.12.0 verification

## Results

- `make test`: gofmt, vet, all package tests with the race detector passed.
- Real PTY acceptance (`scripts/verify-release.py`, local loopback fake
  Responses provider on macOS): **27 checks passed**, covering first-run
  home bootstrap and `defaults --reset`, layered config loading
  (`--config`, `--no-default-configs`, override warnings), Lua VM isolation
  (no injected `print`, `task`, `sh`, or `require("zel")`), shared closure
  upvalues, subprocess timeout reset, `defaults.lua` (`sh`, `cd`, atomic batch
  `edit`, `grep`), `zel exec` timeout reporting, and missing-session
  diagnostics.
- Real PTY regression (`scripts/verify-terminal.py`, local loopback fake
  Responses provider on macOS): **124 checks passed**, covering provider-less
  startup diagnostics, composer and `@`/`#` completions, model/effort
  persistence to `connect.json`, `keys.menu` closing, `commands` execution and
  hotkeys, `Config` screen and `Ctrl+R` reload (including keeping the prior
  config on syntax errors), `zel status` (`new`, `-i`, `--done`), `zel steer`
  with image attachment, `zel print`, `zel choice`, `zel rename`, session
  resume, and Tracing views (`All`, `Lua`, entry navigation, `Ctrl+H` hooks
  toggle).
- No live external provider or Linux runtime checks were run for this
  verification.

## Reproduce

```sh
make test
mkdir -p /tmp/zel-012-bin
go build -o /tmp/zel-012-bin/zel .
/tmp/zel-012-bin/zel version
uv run --python 3.11 --with pyte --with pillow --no-project \
  python scripts/verify-release.py /tmp/zel-012-bin/zel /tmp/zel-012-verify/release
uv run --python 3.11 --with pyte --with pillow --no-project \
  python scripts/verify-terminal.py /tmp/zel-012-bin/zel /tmp/zel-012-verify/terminal
```

Both scripts create isolated temporary homes and `ZEL_HOME` directories.
