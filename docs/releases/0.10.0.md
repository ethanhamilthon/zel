# 0.10.0 verification

Breaking release. No automatic migration, compatibility fallback or rollback.

## Results

- `make test`: gofmt, vet, all package tests with the race detector passed.
- Real PTY acceptance: **20 checks passed**, including all TODO096 UI changes.
- Broader real PTY regression: **86 checks passed**, including streaming,
  external editor/nvim, image attachments, hooks, tracing, sessions and modes.
- Manual tmux check with the actual private configuration: model picker opened;
  model and effort selection worked; the configured remote provider returned
  `ZEL_010_OK`; Ctrl+N cleared the answer and opened the picker; a personal
  completion showed its preview; Russian Ctrl+K opened the menu; clean quit.
- The private configuration loaded without warnings/errors: 3 hooks,
  6 completions, 2 instructions. Provider discovery returned 49 models.
  No private settings or API credentials are included in this repository.

## Reproduce

```sh
make test
go build -o /tmp/zel-0.10.0 .
uv run --python 3.11 --with pyte --with pillow --no-project \
  python scripts/verify-release.py /tmp/zel-0.10.0 /tmp/zel-010-evidence
uv run --python 3.11 --with pyte --with pillow --no-project \
  python scripts/verify-terminal.py /tmp/zel-0.10.0 /tmp/zel-010-regression
```

Terminal rendering currently uses the macOS Menlo font. Both scripts use
isolated temporary homes; they do not modify the user's settings.
