# 0.11.0 verification

## Results

- `make test`: gofmt, vet, all package tests with the race detector passed
  (`internal/luart` has its own VM, config and hook tests).
- Real PTY acceptance (`scripts/verify-release.py`): **34 checks passed**, covering
  the lua tool, config functions, `lua_before`/`lua_after` hooks, `#prompt` with
  `show_prompt`, `task.spawn` notifications, `read()` of an image, `choice()`,
  the timeout and VM reset, `edit()`/`grep()`, async hooks, Tracing (Lua view and
  entry), hot reload of `zel.lua`, a broken `zel.lua` keeping the previous config,
  and the model menu writing `connect.json`.
- Real PTY regression (`scripts/verify-terminal.py`, ported to Lua): **97 checks passed**.
- Real provider (gpt-6.2-sol): Lua calls in the TUI and `zel -p`, a task
  notification, `choice()`, an attached image the model recognized, a timeout
  with a fresh VM, and a `zel -p` subagent started by `sh()`.
