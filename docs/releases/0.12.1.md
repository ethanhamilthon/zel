# 0.12.1 verification

## Results

- `make test`: gofmt, vet, all package tests with the race detector passed.
- Real PTY acceptance (`scripts/verify-release.py`, local loopback fake
  Responses provider on macOS): **27 checks passed**.
- Real PTY regression (`scripts/verify-terminal.py`, local loopback fake
  Responses provider on macOS): **146 checks passed**. The new
  `status_persistence` case checks that the working line shows only the time,
  the `zel status` text and the call count; that a session without a status
  shows no status text; that the status stays in the next call and turn; that a
  new status replaces it; and that a new session (`Ctrl+N`) starts without one.
- No live external provider or Linux runtime checks were run for this
  verification.
